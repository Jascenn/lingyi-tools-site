# Privacy Notice

This site does not provide accounts, forms, payments, or a user database.

## Analytics

The page loads a self-hosted Minilytics script from
`https://minilytics.lingyi.workers.dev/js/script.js` with a website identifier.
As with a normal web request, the analytics endpoint may receive standard
request metadata such as the visited page, referrer, browser information, and
IP address. The site does not use advertising trackers.

## External Resources

- Fonts are loaded from jsDelivr.
- Release and source links open GitHub.
- Other links may open Lingyi properties or third-party services.

Those services process requests under their own policies. This notice should be
updated whenever analytics, embeds, forms, or external scripts change.

## Contact

Use the repository issue tracker for non-sensitive privacy questions. Report
security or accidental data exposure through the private process in
`SECURITY.md`.
